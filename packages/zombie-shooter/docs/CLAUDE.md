# CLAUDE.md - Zombie Shooter (向僵尸开炮)

肉鸽射击游戏，俯视角自动射击 + 波次防守 + 肉鸽升级。

## 技术栈

- **游戏引擎**: Phaser.js 3 (auto-shooting, physics, object pooling)
- **UI**: React + Radix UI Themes + CSS Modules/Less
- **通信**: EventEmitter bridge (`bridge.ts`) 连接 Phaser ↔ React
- **端口**: 3010, base: `/zombie-shooter/`
- **比例**: 9:16 (480×853)
- **路径别名**: `@` 指向 `src/`
- **配置文件**: `src/config/` 目录（JSON格式）

## 架构

```
React UI (components/game/*, components/website/*)
    ↕ bridge.ts (gameBridge.emit / gameBridge.on)
Phaser Game (GameScene → Player, BulletManager, EnemyManager, WaveManager, SkillSystem)
```

### 数据传递方式

启动数据通过 `PhaserGame.ts` 的模块变量传递（`setPendingGameData` / `getAndClearPendingGameData`），不依赖事件时序。

## 核心机制

### 关卡系统

- **100 个关卡**，配置在 `src/config/stages.json`
- 通关当前关卡后解锁下一关
- 精英模式显示 "关卡名·精英"
- 10 关以前不掉落传说和神话品质
- 掉落概率根据关卡动态配置，严格按百分比计算
- **地图循环使用**：10 张地图素材循环（`(stage-1) % 10 + 1`）
- **通关记录**：记录血量百分比，显示"完美通关"或"xx%血量通关"

### 挑战结算

- **挑战成功**（波次20完成）：显示奖励，自动领取
- **挑战失败**（城墙被毁）：显示"挑战失败"，根据进度给奖励
- **返回大厅**：已结束直接返回，挑战中需二次确认
- **中途退出**：根据击杀数/总敌人数计算进度，生成对应奖励
- 铜钱奖励（击杀×10）无论通关与否都获得
- **奖励自动领取**：进入结算界面即自动领取，无需手动点击

**奖励计算**：
- 普通难度基础 2 个奖励，精英难度基础 3 个奖励
- 实际奖励 = `floor(基础奖励数 × 击杀数 / 总敌人数)`
- 进度 0% 不给奖励

### 防守墙与玩家
- **城墙**: `y=GAME_HEIGHT-90`，使用城堡素材图片
- **城墙底部**: 网格状砖块填充 (颜色 #735435, depth=6)
- **玩家**: `y=GAME_HEIGHT-60`，使用士兵素材，缩放 0.7
- **城墙血量**: 基础2000 + 装备血量 + 城墙血量词条
- **攻击范围**: 鼠标悬浮人物时显示半透明区域

### 子弹系统
- 对象池管理 (1000 发)，复用不活跃子弹
- **齐射(burst)**: 以人物为圆心，向敌人方向扇形展开
  - 1级: 15° 扇形，2颗子弹
  - 2级: 25° 扇形，3颗子弹
  - 主子弹追踪目标，齐射子弹按角度直线飞行
- **连射(rapid)**: 垂直方向连续发射多排子弹，间距 64px
  - 每排间隔 80ms，轨迹相同
- **齐射+连射组合**: 每条齐射线上的连射子弹沿同一角度飞行
  - 例：齐射2连射2 → 左线两颗沿7.5°飞，右线两颗沿-7.5°飞
- **分裂弹**: 命中敌人后在敌人位置分裂，分裂子弹不再分裂
- **元素子弹**: 选择后自动切换对应素材（火焰/冰冻/电击）
- **子弹层级**: depth=15，在敌人之上
- **子弹大小**: 基础缩放 0.5，最大 1.5，随伤害比例增长
- **碰撞体**: 12×12 像素
- **伤害数字**: 像素字体 PixelFont

### 敌人系统
- 对象池回收 (maxSize=200)，死亡/超出屏幕时回收
- **素材**: 普通僵尸、疾尸、僵尸王使用行走动画素材
- **尺寸**: walker 0.08, runner 0.06, elite 0.1, boss 0.12
- **纵向压缩**: scaleY × 0.8
- **碰撞体**: 横向 100%，纵向 80%
- **精英/Boss**: 同时最多各 1 个，超限后 fallback 为 walker
- **碰撞**: 敌人到达城墙后停止，强制停在 `wall.y - 30`
- **Buff效果**: 冰冻/眩晕时暂停行走动画
- **唯一ID**: 每个敌人分配唯一ID，用于 buff 绑定
- **名字显示**: 精英/首领显示名字（加粗），首领额外显示 HP
  - 精英名字: 14px，首领名字: 16px
  - 首领 HP: 14px，红色加粗
- **击杀精英**: 立即奖励升级卡片选择

### 波次系统
- 间隔 20 秒生成新波次
- 精英: 波次 5、10 出现
- Boss: 波次 14 出现
- 第20波完成后触发通关
- 20波总敌人约 680 个

### 经验值系统
- 动态计算：`xpToNextLevel = totalEnemies / (maxLevel * 2)`
- 20级满后不再出现升级卡牌，经验值不再增加

### 技能系统 (5 系，每系 3 阶)

| 系别 | 初始技能 | 进阶 1 | 进阶 2 | 冷却 | 基础伤害 |
|------|----------|--------|--------|------|----------|
| 风 🌪️ | 风咒 (持续旋风) | 旋风斩 (分裂风刃) | 风卷残云 (碰撞分裂) | 5s | 200 |
| 雷 ⚡ | 雷咒 (单体雷罚) | 惊雷术 (分裂雷罚) | 天雷空破 (连续雷罚) | 3s | 300 |
| 水 💧 | 冰咒 (单体冰冻) | 寒冰破 (冰暴伤害) | 水漫金山 (击退) | 3s | 300 |
| 火 🔥 | 炎咒 (点燃1s) | 爆炎弹 (击退) | 三味真火 (燃烧3s) | 3s | 300 |
| 土 🪨 | 土咒 (单体击退) | 飞岩术 (眩晕) | 泰山压顶 (长眩晕) | 3s | 300 |

**技能伤害公式**: `最终伤害 = (基础伤害 + 元素加成) × 元素增幅倍率`
- 元素增幅倍率 = `1 + 元素增幅等级 × 0.6`
- 元素加成来自装备词条，按元素类型区分
- 元素基础伤害配置在 `skills.json` 的 `elementBaseDamage`

**技能效果**:
- 最多 3 系技能，选满后只显示已有系的进阶技能
- 进阶需要前置技能，满级后不再出现
- HUD 左侧显示技能图标 + 环形冷却进度
- 点击技能图标显示详情面板（基础伤害、元素增幅、元素加成、最终伤害、冷却、技能效果列表）
- 技能图标带 padding 防止裁切

### Buff 系统
- **燃烧**: 每秒造成攻击30%伤害，3秒
- **冰冻**: 完全停止移动和攻击，暂停动画，1秒
- **麻痹**: 减速50% + 无法攻击，1秒
- **眩晕**: 完全停止，暂停动画，1秒
- **流血**: 受到的所有伤害增加30%，5秒
- **减速**: 移动速度降低50%，2秒

### 装备词条系统

装备可附魔宝石，宝石词条在局内生效。词条通过 `affixEffects` 传递给 GameScene。

**触发类词条（命中时概率触发）**:

| 词条 | 效果 | 来源部位 |
|------|------|----------|
| `slow_*` | 攻击有X%概率减速敌人50%，2秒 | 战靴 |
| `stun_*` | 暴击有X%概率眩晕敌人 | 腿甲 |
| `bleed_*` | 攻击有X%概率造成流血 | 肩甲 |
| `teleport_*` | 攻击有X%概率传送敌人回起点 | 战靴 |
| `instant_kill_*` | 攻击有X%概率秒杀 | 肩甲(传说+) |
| `no_ammo_*` | X%概率不消耗弹药 | 头盔 |
| `lifesteal_wall` | 2%概率吸取40%伤害恢复城墙 | 肩甲(神话) |

**属性类词条（被动生效）**:

| 词条 | 效果 | 来源部位 |
|------|------|----------|
| `hit_rate_*` | 命中率（转化为暴击率加成） | 头盔 |
| `attack_*` | 攻击力+X | 肩甲 |
| `crit_rate_*` | 暴击率+X% | 腿甲 |
| `crit_damage_*` | 暴击伤害+X% | 腿甲 |
| `dodge_*` | 闪避率+X% | 战靴 |
| `wall_hp_*` | 城墙血量+X | 盔甲 |
| `wall_shield_*` | 城墙护盾+X | 盔甲 |

**特殊词条**:

| 词条 | 效果 |
|------|------|
| `attack_random*` | 攻击随机增幅 -20%~+X%（品质越高上限越高） |
| `invincible_*` | 城墙血量低于阈值时无敌X秒（一局仅触发一次） |
| `wall_counter_*` | 城墙受击时X%概率反击（2~4倍攻击） |
| `wall_regen_shield` | 每30秒回复10%最大护盾 |
| `burn_extra_damage` | 对燃烧敌人额外造成最大生命值0.01%伤害 |
| `freeze_extra_damage` | 对冰冻敌人额外造成最大生命值0.01%伤害 |
| `paralyze_extra_damage` | 对麻痹敌人额外造成最大生命值0.01%伤害 |

**随机增幅阶梯**:

| 品质 | 范围 |
|------|------|
| 普通 | -20% ~ +30% |
| 优秀 | -20% ~ +40% |
| 精英 | -20% ~ +50% |
| 完美 | -20% ~ +60% |
| 传说/神话 | -20% ~ +70% |

### 元素伤害系统

- 元素伤害按类型区分（fire/thunder/water/wind/earth）
- 装备词条的元素伤害只加成对应系的技能
- 角色属性面板分别显示各系元素伤害
- 元素增幅通过升级卡牌获得（每级+60%）

### 货币系统

| 货币 | 获取方式 | 用途 |
|------|----------|------|
| 🪙 铜钱 | 击杀敌人(10/个) | 装备洗练 |
| 🥈 银锭 | 副本产出（暂未开放） | 预留 |
| 🥇 金条 | 通关宝箱（每关一次） | 商城抽奖 |

货币显示格式：三位逗号分隔（1,000）

### 装备元素伤害系统

- 每个装备有N个元素词条槽位（N = 宝石孔位数，按品质递增）
- 新装备词条为空（"未洗练"），需要手动洗练
- 洗练消耗铜钱，随机生成元素类型（风/雷/水/火/土）和伤害值
- 洗练窗口可反复洗练，进度条+游标动画+元素随机切换
- 元素伤害按类型累加，只加成对应系技能

**装备元素伤害范围**：

| 品质 | 词条数 | 伤害范围 | 洗练费用 |
|------|--------|----------|----------|
| 普通 | 1 | 10~100 | 100铜 |
| 优秀 | 2 | 50~300 | 200铜 |
| 精英 | 3 | 100~600 | 400铜 |
| 完美 | 4 | 200~1000 | 600铜 |
| 传说 | 5 | 400~1500 | 1000铜 |
| 神话 | 6 | 600~2000 | 2000铜 |

### 宝石合成系统

- 5个同品质宝石合成1个随机词条的高一品质宝石
- 仅宝石tab显示"一键合成"按钮
- 合成前弹出确认框，显示参与宝石的词条
- 合成后弹出结果（成功/失败）

**成功率**:

| 合成路径 | 成功率 |
|----------|--------|
| 普通→优秀 | 90% |
| 优秀→精英 | 80% |
| 精英→完美 | 70% |
| 完美→传说 | 50% |
| 传说→神话 | 30% |

- 失败则5个宝石消失
- 成功则生成目标品质的随机宝石（随机部位、随机词条）

### 背包系统

- **分类tab**: 宝石、装备、材料（横向滚动，无滚动条）
- **部位筛选**: 二级tab筛选头盔/盔甲/肩甲/腿甲/战靴
- **品质排序**: 高品质在前（神话→传说→完美→精英→优秀→普通）
- **品质颜色**: 宝石属性面板词条文字颜色与品质一致
- **自动鉴定**: 装备获取后自动鉴定，无需手动操作

### 核心/装甲展示

- 核心页面展示所有核心和装甲（5元素×3等级/阶级）
- 悬浮显示详细属性（技能描述、冷却、装甲效果）
- 未拥有的显示半透明+"未拥有"标记

### 掉落系统

- 掉落概率配置在 `src/config/stages.json`，严格按百分比计算
- 100 关概率递减：普通从 92% 递减，优秀/精英/完美递增
- 传说从第 10 关开始出现，神话从第 20 关开始
- 大厅显示当前关卡的掉落概率表（横向排布，所有品质都显示）

### 城墙护盾系统

- 护盾优先于血量扣减
- 护盾回复词条：每30秒回复10%最大护盾
- 护盾状态通过 `wall:shield-changed` 事件发送

### 伤害统计
- 按来源分类：枪械、风系、雷系、水系、火系、土系、燃烧、爆炸
- 横向柱状图显示，标签在柱上方
- 点击左侧图标显示/隐藏

### 枪械属性显示
- 伤害: 基础 (+装备加成)
- 增幅: 升级加成百分比
- 最终伤害: 含随机增幅范围
- 齐射/连射/分裂/暴击/暴伤/爆炸

### 升级卡牌分类

| 类别 | 说明 |
|------|------|
| gun | 枪械相关 (增伤/齐射/连射/分裂/元素弹) |
| skill | 技能相关 (5 系 × 3 阶) |
| element | 元素伤害 (+60%，需有对应系技能) |
| heal | 回血 (仅在掉血时出现) |

### 伤害公式
- 基础伤害: baseDamage=100
- 暴击: 3x 伤害
- 技能伤害: (元素基础伤害 + 元素加成) × 元素增幅倍率
- 元素增幅倍率: 1 + 等级 × 0.6
- 元素伤害: 无视防御
- 子弹大小随伤害增加（基础0.5，最高1.5）
- 爆炸伤害: 30%概率触发，1.5倍伤害，范围50px，最多3个目标

## UI 样式

- **主题**: 固定深色主题
- **弹窗**: 统一透明高斯模糊风格 `rgba(30,30,50,0.85)` + `backdrop-filter: blur(12px)`
- **卡片**: 使用 `SectionCard` 组件，背景 `rgba(0,0,0,0.2)`，圆角 12px
- **HUD**: 标题绝对定位居中，经验条留出间距
- **装备槽**: 竖向排列，显示图标+名称+品质
- **人物卡片**: 单独卡片，撑满剩余空间
- **属性卡片**: 角色属性和宝石属性平分宽度，元素伤害按系别分别显示
- **背包卡片**: `flex: 1` 撑满剩余空间
- **移动端**: 隐藏 Header/Footer，全屏游戏
- **货币显示**: 三位逗号分隔（1,000格式）
- **移动端点击**: `-webkit-tap-highlight-color: transparent` 去除蓝色高亮框

## 注意事项

- 墙体用 `this.add.sprite()` 不用 `this.physics.add.sprite()`
- 敌人回收必须 `body!.reset(0, 0)` 再放回池
- 子弹回收时重置纹理为普通子弹
- 敌人使用唯一ID绑定 buff，不用位置坐标
- 技能冷却信息通过 `skills:updated` 事件发送
- 启动数据通过模块变量传递，不依赖事件时序
- 导入路径使用 `@/` 别名（CSS模块仍用相对路径）
- `formatNumber` 和 `stageNames` 已提取到 `src/utils/`
- 关卡配置在 `src/config/stages.json`，方便独立编辑
- 所有游戏数据配置在 `src/config/*.json`，改数值只需编辑 JSON
